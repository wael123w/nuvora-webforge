Nuvora WebForge

Installation & User Guide

Windows desktop application

1. Introduction

Nuvora WebForge is a Windows desktop application that turns a written brief into an editable website project. It connects directly to your selected AI provider from the desktop application; no bundled server, Ruby, Rails, Docker, or database is required.

Included capabilitiesWhat you control
HTML/CSS/JavaScript or React + Vite website generationYour provider, model, API key, prompt, reference image, files, and export location
Desktop, tablet, and mobile preview modesGenerated project files through an integrated Monaco code editor
Gemini, Ollama, LM Studio, and OpenAI-compatible local endpointsWhether generation uses a cloud service or a local model

3. Installation

  1. Extract the downloaded product package.
  2. Open the Installer folder.
  3. Double-click Nuvora-WebForge-Setup.exe.
  4. Choose the installation folder and follow the installer steps.
  5. Launch Nuvora WebForge from the desktop or Start Menu shortcut.

The application does not need Ruby, Rails, Node.js, npm, or a web server after installation.

4. Configure an AI provider

Select Settings in the upper-right corner. Choose Google Gemini for a cloud provider, or Local LLM for Ollama, LM Studio, and compatible OpenAI-style endpoints. Enter the required details, select Test Connection, then save the settings.

Gemini

Enter your Gemini API Key and choose a supported model. The key is stored locally using the operating system’s secure storage when available and is not exposed to the visible React interface.

Local LLM

Enter the local server URL and model name. For Ollama, a typical URL is http://localhost:11434. For a compatible API, enter its local URL and model name.

5. Generate a website

  1. Enter a clear website brief in the left-hand panel. Describe the business, pages, sections, language, colors, style, and responsive behavior.
  2. Choose HTML / CSS / JS for a static website or React + Vite for a React project.
  3. Optionally drag a PNG, JPG, or WEBP reference image into the image area.
  4. Select Generate Website.
  5. Review the result in Preview, Code, and Files.

Each accepted HTML project includes root files plus an organised folder containing separate styles, JavaScript, and supporting project files. Each accepted React project includes root configuration files and organised source folders. The application rejects incomplete single-file or two-file project responses.

Prompt tip: Mention the desired pages, user actions, style direction, language, and screen sizes. More specific requirements generally make review easier.

6. Review, refine, edit, and save

Use the workspace tabs to switch among Preview, Code, and Files. Preview modes simulate desktop, tablet, and mobile widths. Select a file from the project tree to edit it with Monaco Editor, save the file, then refresh the preview. Use the folder or export control to copy the completed project to a directory you choose.

Refine with AI

After generation, describe one specific requested change in the Refine with AI panel. The application sends the request together with the current project file snapshot to your selected provider. The provider must return a complete replacement structure; Nuvora WebForge validates it before atomically replacing project files and refreshing the preview. If the request is cancelled or validation fails, the existing project remains unchanged.

Generated files remain normal editable project files. Review all generated code before deploying it to production.

7. Customize branding and themes

All generated projects remain normal editable source files. For static projects, update the colour variables, typography, markup, and local assets in the root files and assets/ folder. For React + Vite projects, update src/styles.css, src/App.tsx, the files in src/components/, and any content data files.

GoalRecommended approach
Change colours or typographyEdit the CSS variables and component styles, then review the result in the relevant project runtime.
Replace logos or imagesAdd buyer-owned local assets, then update the related HTML or component markup.
Change content or a sectionEdit the file in Code or write a precise request in Refine with AI and review the returned project.
Brand safety: Do not place API keys or private credentials into generated client-side code.

8. Technical reference and dependencies

The complete architecture, application file map, generated-project structures, provider requirements, and dependency instructions are available in TECHNICAL-REFERENCE.md. For a control-by-control walkthrough of the interface, open INTERFACE-TOUR.md.

Running generated React + Vite projects

After copying a React + Vite project to a working folder, open a terminal in that folder and run pnpm install, then pnpm dev. Use pnpm build to create a production bundle. The installed Nuvora WebForge desktop application itself does not require these commands.

9. Troubleshooting

IssueRecommended check
Connection test failsVerify the key, model name, internet connection, or local endpoint URL. Confirm that the local model server is running before testing.
Generation returns invalid contentRetry with a model that supports structured JSON output and reduce an overly broad prompt.
Preview is emptyOpen the generated project files and confirm that an index.html entry file was generated. For React, follow the generated project instructions.
Key is missing after a reinstallRe-enter the key in Settings. Keys are intentionally stored per Windows user profile and are not bundled in the installer.
