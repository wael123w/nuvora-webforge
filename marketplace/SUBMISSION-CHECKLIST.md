# CodeCanyon resubmission checklist

## Product package structure

| Folder | Required content | Status |
|---|---|---|
| `Installer/` | Windows NSIS installer EXE | Included. |
| `Documentation/` | English HTML user guide, technical reference, and image assets | Included. |
| `Source_Code/` | Electron, React, TypeScript, scripts, and build configuration | Included without `node_modules` or build output. |
| `Marketplace_Assets/` | Listing copy, cover, compliant preview images, and this checklist | Included. |
| Root files | Licence, release notes, and integrity checksum | Included. |

## Review feedback addressed

| Envato review item | Required resubmission state |
|---|---|
| Unique branded title | Use `Nuvora WebForge | AI Website Generator for Windows`. |
| Preview dimensions | Include at least two landscape screenshots at 1280×720 or larger, exactly 16:9, and at least two portrait screenshots with heights between 700 and 900 pixels. |
| Version-free copy | Do not show a specific release number in What is included, Installation, or listing copy. |
| Self-contained licence wording | Do not offer separate source-code deals, off-platform purchasing, or external licence arrangements. |
| Documentation depth | Include annotated screenshots, branding/theme customization guidance, architecture reference, file-structure breakdown, and dependency management instructions. |
| Tags | Use only the concise tag list in `ITEM-LISTING-EN.md`; do not add redundant desktop-builder variations or the generic `c` tag. |
| Inline banner | Upload the updated benefit-led English banner instead of legacy Arabic or version-badged artwork. |

## Before uploading

- [ ] Test the EXE installer on a clean Windows 10/11 device.
- [ ] Select the exact CodeCanyon category shown in the author dashboard.
- [ ] Paste the exact branded title from `ITEM-LISTING-EN.md`.
- [ ] Upload the updated cover, at least two compliant landscape previews, and at least two compliant portrait previews.
- [ ] Copy the concise tags exactly; do not add redundant tags.
- [ ] Upload the customer ZIP rather than source folders individually.
- [ ] Host `Documentation/index.html` publicly and add its URL to the item page if the dashboard provides a documentation URL field.
- [ ] Specify the support period, support contact path, price, and author details.
- [ ] Confirm that every visual asset is original or commercially licensed.
- [ ] Confirm that no API key, user project, local logs, or private settings are included in the ZIP.
- [ ] Review listing copy and FAQ for self-contained Envato licence wording only.
