## Title

**Nuvora WebForge | AI Website Generator for Windows**

## Short description

Generate, refine, preview, edit, and export structured HTML or React + Vite website projects from a Windows desktop application powered by Gemini or a local LLM.

## Full description

Nuvora WebForge is a compiled Windows desktop application that turns detailed website briefs into editable, organised website projects. This customer download contains the Windows installer and English documentation; source code is not included. It provides a focused prompt-to-project workflow without requiring Ruby, Rails, Docker, a database, or a separate web server after installation.

Choose Google Gemini for cloud generation, or connect Ollama, LM Studio, and compatible OpenAI-style local endpoints. Add an optional visual reference, select HTML/CSS/JavaScript or React + Vite output, review the project in responsive modes, edit files with Monaco Editor, and copy the completed project to any folder.

After a project is generated, the **Refine with AI** panel lets the buyer describe a targeted change. Nuvora WebForge sends the requested change and the current project files to the selected provider, validates the complete returned structure, and refreshes the project after the updated files are safely written.

### Key features

- Standalone Windows desktop application with an NSIS installer EXE.
- Direct Google Gemini integration through the desktop application.
- Local LLM support for Ollama, LM Studio, and OpenAI-compatible endpoints.
- HTML/CSS/JavaScript and React + Vite generation modes.
- Required multi-file project structure with root files and organised folders.
- Optional PNG, JPG, and WEBP visual reference input.
- Desktop, tablet, and mobile preview modes for static HTML projects.
- Integrated Monaco code editor and project file browser.
- Targeted project refinement through the selected AI provider.
- Secure local storage for provider settings and API keys where Windows secure storage is available.
- Project copy/export to a chosen local folder.
- English product documentation, annotated interface screenshots, and a technical reference.

### Who it is for

Nuvora WebForge is designed for web developers, designers, agencies, freelancers, product teams, and technical creators who want to accelerate website prototyping while keeping normal editable project files.

### FAQ

**Does the buyer need to install Node.js, pnpm, Ruby, Rails, or a web server to use the desktop application?**

No. The Windows installer installs and launches Nuvora WebForge as a desktop application. Extra software is only required if the buyer chooses a local AI provider such as Ollama or LM Studio.

**Is source code included?**

No. This is a compiled Windows application package that includes the installer and English customer documentation. Use of the download is governed by the applicable Envato licence selected at purchase.

**Which AI providers are supported?**

Google Gemini is supported directly. The Local LLM option supports Ollama, LM Studio, and compatible OpenAI-style local endpoints.

**Can the buyer edit a generated website after creation?**

Yes. The project files can be edited in the integrated Monaco editor. The buyer can also submit a targeted change through Refine with AI, subject to the selected provider returning a valid complete project structure.

### Important notes

Third-party AI keys, model subscriptions, and usage charges are not included. The buyer supplies their own provider credentials. Generated code should always be reviewed and tested before production deployment.
